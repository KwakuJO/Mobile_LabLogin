# Welcome to an Expo app 👋

This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app), and the project is modified / made by Kwaku Otchere.

## Get started

1. Install dependencies

   ```bash
   npm install 
   npm install react-native-url-polyfill
   npm install zod react-hook-form @hookform/resolvers
   npm install @react-native-async-storage/async-storage
   npm install @supabase/supabase-js
   ```

2. Start the app

   ```bash
   npx expo start
   ```
